## Hey, I'm Ayotomiwa 👋

Design engineer expanding into **AI systems engineering** — bringing thoughtful design and intelligent systems together.

I care about interfaces that *feel* like something: motion, texture, the sense that a surface reacts to you. Lately I've been putting models behind them.

📍 Dallas, Texas &nbsp;·&nbsp; 🌐 [ayotomcs.me](https://ayotomcs.me) &nbsp;·&nbsp; ✉️ hello@ayotomcs.me

### What I'm building

- **[tomcs](https://github.com/tomiwadoesux/tomcs-registry)** — a visual IDE for terminal user interfaces, built with React and Ink. Design, theme and architect CLIs instead of guessing at them.
- **[Trilorah](https://github.com/tomiwadoesux/trilorah2)** — church presentation software with an agentic sermon engine. Beautiful, effortless, intelligent.
- **[JustClarify](https://github.com/tomiwadoesux/JustClarify)** — an AI reading companion that explains whatever you highlight, using the context around it, without pulling you off the page.
- **[PhotoBook](https://github.com/tomiwadoesux/Ayotomcs-Photos)** — a photo archive, built like it is still the golden age of Instagram.

### Toolkit
